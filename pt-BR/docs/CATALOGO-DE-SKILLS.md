# Catálogo e roteamento de skills

Este catálogo é uma orientação inicial baseada nos nomes informados pelo autor. Não comprova que uma skill esteja instalada em cada computador.

## Procedimento obrigatório
1. Descubra o nome e o caminho exatos no ambiente local.
2. Leia as instruções da skill.
3. Verifique pré-requisitos e compatibilidade.
4. Siga as instruções reais ao utilizar a skill.
5. Registre como utilizada somente se realmente foi usada.

Se uma skill não estiver disponível, não finja sua execução. Registre a limitação e use uma alternativa segura quando possível. Não execute todas as skills em toda tarefa.

## Skills transversais e condicionais
- `context7-mcp`: documentação da versão correta de uma biblioteca, se instalada.
- `security-audit` e `security-review`: critérios de segurança pertinentes.
- `using-git-worktrees`: tarefas paralelas que realmente precisam de isolamento.
- `verification-before-completion`: conclusão baseada em evidências.
- `caveman-compress`: compactação somente após ler as instruções.
- `caveman-stats`: métricas somente se a ferramenta as disponibilizar.
- `cavecrew`: somente se complementar o orquestrador sem criar coordenação concorrente.
- `fewer-permission-prompts`: nunca use para contornar segurança ou ampliar permissões desnecessariamente.

Para Flutter/Dart, selecione skills pertinentes de `dart-flutter`, `vgv-ai-flutter-plugin` e `flutter`. Para interface/UX, considere `design-system`, `design-critique`, `design-handoff`, `accessibility-review` e `design-branding`. Não utilize skills específicas de uma tecnologia em projetos que não a usam.
